# 📝 To-Do List Application

A simple, responsive, and user-friendly To-Do List web application developed as a **BCA Mini Project** using HTML, CSS, and JavaScript.

This application helps users organize their daily activities by adding, editing, deleting, and tracking tasks efficiently.

## 🚀 Features

* ➕ Add new tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ✅ Mark tasks as completed
* 📋 View all tasks
* ⏳ Filter pending and completed tasks
* 🧹 Clear all completed tasks
* 💾 Save tasks using browser LocalStorage
* 📱 Responsive user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser LocalStorage

## 💻 How to Run the Project

1. Download or clone this repository.
2. Extract the project folder if downloaded as ZIP.
3. Open the folder in Visual Studio Code.
4. Open `index.html` in your browser.
5. Start adding and managing your tasks!

No database or backend server is required.

The main objective of this project is to develop a basic task management system that helps users organize their daily activities while understanding frontend web development concepts such as DOM manipulation, event handling, and browser data storage.
